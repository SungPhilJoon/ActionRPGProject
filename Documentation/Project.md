# 프로젝트 설명

어떤 게임을 만들지에 대한 설명

1. VRising을 리버스한 프로젝트를 만든다. VRising과 똑같은 게임을 만드는 것을 목표이다.
2. VRising의 수익 부분은 판단하지 않고 모든 아이템은 공짜로 살 수 있게 만들어야 한다.
2. 최대 4인 협동 게임을 만들 것이고, 4인이 아니여도 1인으로 오프라인으로 즐겨도 되고 2인 이상 플레이도 가능하게 만드는 것이다.
3. 에셋은 현재 계정에 있는 에셋을 사용해서 만들 것이다. 뷰족한 에셋이 있다면 얘기해서 조율하는 것으로 맞춰 갈 것이다.
4. Demo 버전의 게임을 만들 것이다. 큰 규모의 게임을 만드는 것이 아니라 포트폴리오에 제출할 수 있을 정도로 만드는 것이다.
5. 최적화나 프로파일링은 내가 직접해서 경험을 쌓는 방식으로 진행할 것이다. 문제점을 같이 파악하고 어떤 방법으로 해결할 지에 대해서 논의 정도만 할 것이므로 현재는 구현에만 취중한다.
6. 먼저 오프라인 플레이가 가능하게 만들었으면 좋겠다. 플레이를 통해 게임의 성능 테스트를 하기 위함이다.
7. 프레임워크에 대한 내용은 다음 내용에서 확인한다.

# 프레임워크 설정

현재 코드 구조를 프레임워크 식으로 개발하여 유지보수 측면을 늘려 사람이 직접 수정할 수 있도록 만드는 것이 목표이다.

1. string 비교와 string을 직접 하드코딩하는 식으로 개발하지 말아야 한다. index를 int형으로 설정하여 되도록이면 int 값을 비교하여 확인할 수 있게 한다. 아니면 Bit 연산자를 통해 long 타입을 compare 하는 방식이나 hash를 통한 방식으로 사용한다.
2. 게임의 정적 데이터는 csv 테이블을 이용한다. csv 테이블의 데이터를 이용하여 게임의 밸런스와 어떤 아이템이 icon으로 노출될 지 설정한다.
3. csv 데이터 테이블은 ScriptableObject로 변환해서 읽게 만들 것이다.
4. 게임 밸런스 툴을 만들어야한다. 밸런스 툴은 게임의 전투 시스템이 어떻게 동작하고 있는지 어떤 공격을 받아 현재의 데미지의 총합을 확인할 수 있는 툴을 개발하거나 UI를 간편하게 만들 수 있는 Factory 툴을 개발한다. 후에 툴은 나중에 개발 과정을 통해 확인한다.
5. 에셋을 Load하는 방식은 Asset Addressables를 사용하여 Load하는 방식으로 사용한다. 비동기식으로 Load하는 방식을 추구하되, Race Condition 이슈로 인한 댕글링 포인터 이슈가 발생하게 된다면 동기식으로 Load 하게 한다.
6. URP를 사용하여 게임의 퀄리티를 높이는 방식으로 개발한다. URP 기능을 활용한 부분은 직접 설명한 md 파일을 만들어서 설명하게 해야 한다. 후에 최적화는 다시 고민한다.
7. 게임의 맵은 일단 하나만 만들고 맵은 Terrain을 사용하여 만든다. Terrain에 필요한 풀과 나무 그리고 텍스쳐는 외부에서 License에 걸리지 않는 무료 에셋을 가져와서 만들어야한다.
8. 언리얼의 GAS 시스템을 충분히 활용하고 활용한 시스템에 대한 구체적인 내용은 md 파일을 따로 만들어서 알려주어야 한다.
9. Cheat를 도입하여 게임의 밸런스 테스트를 자유롭게 할 수 있도록 만들어야한다.

# 프로젝트 개발시 유의사항

프로젝트 개발 중 지켜야 할 사항이다.

1. 모르는 부분이나 구현할 수 없는 부분은 솔직하게 말해서 추측하지 않고 만들어야 한다.
2. 에셋이 필요한 것이 있으면 필요한 에셋에 대한 md 파일을 만들어서 제출한다.
3. 코딩 방식은 E:\PhilJoon\UnityProject\frameworkLib\Assets\Scripts의 방식을 따라서 개발한다. 하지만 분기문이나 3항 연산자에서 == null, == false, == true 이런 식으로 개발하여 표현식을 작성해야 한다.
4. 코딩 방식은 언리얼 방식이 아닌 유니티 방식으로 개발하며 앞에 _를 붙이는 변수 선언은 하지 말아야하며, private한 함수는 앞에 소문자부터 시작하도록 만든다.
5. 공통적인 방식은 Util로 따로 추출해서 개발한다.
6. 디자인 패턴을 사용했다면 어떤 디자인 패턴을 사용했는지 md 파일로 만들어준다.
7. 개발 시 문제 상황이나 문제가 되는 부분, 그리고 문제를 해결한 방법은 md 파일로 만들어준다.
